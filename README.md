# NAFAS | نَفَس

تطبيق Android عربي لمساندة الإقلاع عن التدخين ومتابعة شرب الماء.

## المزايا
- واجهة عربية RTL بتصميم داكن متجاوب.
- أيقونة تطبيق باسم NAFAS.
- عداد إقلاع يتحدث كل ثانية.
- خط زمني تفاعلي للتغيرات المتوقعة في القلب والدم والرئتين، محسوب من وقت آخر سيجارة.
- متابعة شرب الماء وسجل يومي وهدف قابل للتعديل.
- تذكيرات ماء بإشعارات Android عبر WorkManager.
- حفظ محلي للبيانات على الجهاز.

## بناء APK
يُبنى Debug APK تلقائياً عبر GitHub Actions عند كل push إلى main أو يدوياً من تبويب Actions.
الملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات صحية مهمة
مراحل التعافي في التطبيق تقديرات سكانية عامة وليست قياساً حياً لمستويات النيكوتين أو أول أكسيد الكربون أو تشبع الأكسجين. لا يستطيع الهاتف قياس هذه القيم من دون أجهزة طبية مناسبة. تختلف سرعة التعافي بين الأشخاص. لا يقدّم التطبيق تشخيصاً ولا يغني عن الرعاية الطبية. ضيق التنفس الشديد أو ألم الصدر أو الإغماء يستلزم تقييماً طبياً عاجلاً.

هدف الماء الافتراضي 1600 مل وهو إعداد ابتدائي قابل للتغيير، وليس توصية طبية شخصية.
